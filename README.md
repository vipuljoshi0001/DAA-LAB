# About This Repository

This repository contains all the laboratory programs and implementations completed during the full semester of the **Design and Analysis of Algorithms (DAA) Lab** course.

The repository is organized week-wise from **Week 1 to Week 8**, and each week contains three questions/programs implemented in **C++**.

---

# Topics Covered

## Week 1 – Searching Algorithms
- Linear Search
- Binary Search
- Jump Search

## Week 2 – Advanced Searching
- Frequency Count in Sorted Array
- Find Three Elements (arr[i] + arr[j] = arr[k])
- Count Pairs with Difference K

## Week 3 – Sorting Algorithms
- Insertion Sort
- Selection Sort
- Duplicate Element Detection using Sorting

## Week 4 – Divide and Conquer & Advanced Sorting
- Merge Sort
- Quick Sort using Random Pivot
- Kth Smallest Element (Quick Select)

## Week 5 – Advanced Algorithms
- Maximum Frequency Character
- Two Elements with Given Sum
- Common Elements in Two Sorted Arrays

## Week 6 – Graph Algorithms
- Depth First Search (DFS)
- Breadth First Search (BFS)
- Cycle Detection in Directed Graph

## Week 7 – Shortest Path Algorithms
- Dijkstra’s Algorithm
- Bellman-Ford Algorithm
- Shortest Path with Exactly K Edges

## Week 8 – Minimum Spanning Tree
- Prim’s Algorithm
- Kruskal’s Algorithm
- Maximum Spanning Tree
